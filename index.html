Quick start

  1. Create a class in Students & Classes.
  2. Paste student names, one name per line, then add them.
  3. Record attendance every school day in Daily Attendance.
  4. Check daily, weekly, monthly or yearly totals in Reports.

Data & privacy

  • Records are stored locally in this browser, not automatically synced across devices.
  • Use the same browser and device for consistent records.
  • For use on another device, download a backup and restore it there.
  • Avoid sharing backups because they contain student information.

For best results, keep a backup at least weekly and before changing phones or clearing Chrome data.
